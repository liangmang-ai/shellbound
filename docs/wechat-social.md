# 社交功能状态：暂时撤下

本版暂时撤下微信头像昵称授权与好友排行榜。首页、合作房间和结算界面不提供授权、好友榜或云成绩同步入口，客户端不再引入相关 SDK 调用，`game.json` 不再配置开放数据域。重新构建会删除旧的生成文件 `dist/wechat/open-data/index.js`，同时保留微信工程的 Git、私有配置和其他用户文件。

合作房间和战斗用「1P／2P」编号区分双方，战斗角色仍为默认蛋形角色。界面沿用原双人版的布局比例，并增加圆角、按压反馈和统一的难度选择栏；现有单人和双人玩法、三次免费复活、波间三秒等待及联机画面平滑修复均继续保留，单人本机最高分照常存储。服务端不保存或转发旧客户端发来的头像昵称，旧 `profile` 消息会被忽略；新客户端也忽略旧服务端返回的这些资料。

本次只改代码与构建产物，不更改微信后台的隐私声明，不读取或删除此前的微信云成绩。双人合作仍使用原有微信云托管身份鉴权，因此撤下头像昵称和好友榜不等于整个联机服务完全不处理用户信息；后台声明应继续按实际处理情况填写。

发布时重新构建并上传小游戏客户端；执行服务端流水线，使旧客户端发来的资料也不再被接收保存。代码提交和本地测试不代表已替换云端服务或已上传的体验版。此前社交实现保留在 Git 提交 `f2f5872` 中；未来重新启用前，需要先完成相应后台声明、权限配置及真实微信授权和好友成绩读写验证。
