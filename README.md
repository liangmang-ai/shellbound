# 蛋壳突围 · SHELLBOUND

一个原创蛋形角色的俯视生存射击 MVP。选择地图，清理逐波出现的怪物，拾取武器、弹药、护盾和手雷，完成十波挑战。工作名和视觉风格均可继续调整。

## 运行浏览器试玩版

需要 Node.js 20 或更新版本。

```sh
npm install
npm run build
npm run dev
```

打开 <http://127.0.0.1:5173>。开发服务只监听本机，修改源码后重新执行 `npm run build` 并刷新页面。端口占用时可使用 `PORT=5174 npm run dev`。

```sh
npm test
npm run test:browser
```

`npm test` 运行核心玩法与无 DOM 的微信入口验证。浏览器检查需要本机安装 Google Chrome；它检查键鼠、双摇杆触控、暂停与重开，并在 `artifacts/` 保存截图。运行浏览器检查前先构建。

## MVP 内容

- 两张原创地图：庭院、温室，包含不同障碍和行走路线。
- 三种敌人：普通怪、疾跑怪、重甲怪，十波逐渐升级。
- 现有紫色重甲怪作为 Boss，约每 4 秒发动一次远程攻击，先有 0.85 秒锁定方向的预警，再发射三枚扇形弹丸。预警期间 Boss 停下，侧移或掩体都可躲避；弹丸先消耗盾牌，不伤其他怪物。
- 小怪数量每波增加；第 3 波起出现 Boss，之后每两波增加一名，第 10 波有四名。敌人生命与速度也随波次递增。
- 六种枪：手枪、冲锋枪、步枪、机枪、狙击枪、霰弹枪；射速、散布、伤害和弹匣各不相同。
- 霰弹枪一次消耗一发弹药，散射七枚弹丸，近距离威力大，远距离伤害衰减，最大射程 300；弹匣六发。
- 地面补给：新武器解锁，重复武器补充相应弹药，以及生命、护盾、手雷补给。
- 护盾是吸收伤害的护甲，上限 100，消耗后通过拾取补充。
- 手雷初始 3 枚，朝瞄准方向投掷，延迟产生范围爆炸。
- 单人闯关、失败重开、通关结算和本地最高分记录。

手枪提供无限备用弹药，并保留弹匣和换弹机制。其他枪械有有限弹药；拾取新枪后由玩家自行切换。

每波清关后立即开始下一波，无需等待或确认；补给仍会掉落，靠近即可拾取弹药、盾牌、生命和手雷。第 1、2、3、5、7 波清关分别保底解锁冲锋枪、霰弹枪、步枪、机枪和狙击枪。第 10 波清关后进入通关结算。MVP 中手雷投掷会受障碍阻挡，爆炸范围可覆盖障碍另一侧敌人，不伤玩家。

## 操作

| 操作 | 电脑 | 横屏手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准、射击 | 鼠标瞄准，按住左键射击 | 拖动右摇杆，瞄准并持续射击 |
| 换枪 | 1–6 选择 / Q 轮换（6 为霰弹枪） | 点击底部武器卡 |
| 换弹 | R | 换弹按钮 |
| 投手雷 | G | 手雷按钮 |
| 暂停 | Esc / P | 暂停按钮 |

切到后台时暂停战斗，恢复后可继续。手机竖屏时建议旋转到横屏；微信构建固定横屏。

## 微信小游戏构建

```sh
npm run build
```

产物位于：

```text
dist/web/       浏览器版：index.html、app.js、source map
dist/wechat/    微信版：game.js、game.json、project.config.json
```

在微信开发者工具中以「小游戏」项目导入 `dist/wechat`。当前 `wechat/project.config.json` 的 AppID 为占位值 `touristappid`；使用你自己的小游戏 AppID 替换源码配置后重新构建。开发者工具允许的测试方式和 AppID 权限以实际工具为准。参考 [微信官方小游戏示例配置](https://github.com/wechat-miniprogram/minigame-lockstep-demo/blob/master/project.config.json)。

微信入口使用 `wx.createCanvas`、触摸事件和本地存储；菜单、HUD 与战斗都在 Canvas 内绘制。打包后没有浏览器 DOM 依赖，也没有后端接口。

**微信开发者工具运行、微信真机操作、不同机型性能和平台提审均未验证。** 当前交付是可构建的小游戏工程和浏览器试玩版，不能等同于已上线微信小游戏。正式发布前需要真实 AppID，并完成开发者工具、Android/iOS 真机及平台审核流程。

## 源码结构

```text
src/game.js       战斗、敌人、地图、波次、掉落与装备规则
src/app.js        输入、Canvas 界面与游戏状态切换
src/render.js     原创角色、场景、HUD 与战斗效果绘制
src/browser.js    浏览器启动及输入、页面生命周期适配
wechat/game.js    微信启动及触摸、后台生命周期适配
scripts/build.mjs  两个平台打包
scripts/serve.mjs  浏览器本地服务
web/index.html    浏览器页面
```

浏览器和微信共用玩法与渲染代码；画布使用逻辑像素输入，由应用处理设备像素比。

## 原创素材与范围

人物、怪物、地图、界面和效果均由本项目 Canvas 代码绘制，不引用《僵尸危机 3》/Boxhead 的美术、音效、地图或源代码。此版本采用通用的俯视射击、波次闯关与拾取补给机制。新增素材时继续保留作者和授权信息；项目的原创制作说明不构成法律结论。

MVP 暂未包含联网双人、排行榜服务、微信登录、广告、付费、持久账号系统或正式发行配置。
