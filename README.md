# 蛋壳突围 · SHELLBOUND

一个原创蛋形角色的俯视生存射击 MVP。选择地图，清理逐波出现的怪物，拾取武器、弹药、护盾、手雷和爆发道具，挑战不断增强的无尽攻势。工作名和视觉风格均可继续调整。

## 运行浏览器试玩版

需要 Node.js 20 或更新版本。

`npm run build` 会重新创建 `dist/web` 和 `dist/wechat`。当前已导入的微信工程目录含本地 Git 仓库与私有配置，重构建前请备份这些内容，并在构建后恢复；仅更换 AppID 无需重构建。

```sh
npm install
npm run build
npm run dev
```

打开 <http://127.0.0.1:5173>。开发服务只监听本机，修改源码后重新执行 `npm run build` 并刷新页面。端口占用时可使用 `PORT=5174 npm run dev`。

```sh
npm test
npm run test:browser
```

`npm test` 运行核心玩法、地图机关、辅助瞄准、音效和无 DOM 的微信入口验证。浏览器检查需要本机安装 Google Chrome；它检查键鼠、多点触控、三种手机及两种平板横屏尺寸、暂停与重开，并在 `artifacts/` 保存截图。运行浏览器检查前先构建。

## MVP 内容

- 两张原创地图：汽泡工坊调整为默认第一张，保留机器掩体、油桶与加速带；第二张为星糖回廊，采用中心星糖岛、四组交错弯墙和内外双环，左右加速星带可帮助绕行。薄荷庭院不再出现在选择界面。
- 工坊四个油桶点位：油桶 44 生命，手枪两发引爆，支持手雷与连锁爆炸；范围 145、对敌中心伤害 155，距离越远伤害越低。玩家会受到 18–45 伤害，先消耗护盾，同一连锁只承受一次最强伤害；受伤和复活保护期间免伤。打爆后 12 秒在原点补充，空位显示倒计时。油桶不算本波怪物，也不阻挡行走。
- 两条箭头加速带：玩家处于带内时移速为 1.45 倍，离开立即恢复；怪物不加速，效果不叠加。暂停或切到后台时，地图刷新倒计时也会停止。
- 三种敌人：普通怪、疾跑怪、重甲怪，随波次逐渐升级。玩家与怪物、怪物之间都有圆形实体碰撞，贴墙可滑动，接触仍会受伤。出怪点拥挤时在入口附近寻找空位或等待重试，不叠放怪物。
- 首页可选择休闲、标准、挑战三档难度，默认休闲，选择保存在本机。休闲普通怪数量约为标准的60%、生命72%、速度80%、敌人伤害65%，出怪间隔加长，Boss约6秒射击一次且预警更长；标准保留原来的数量与强度，挑战增加数量、生命、速度与攻击频率。武器解锁、无尽流程与3次复活在三档中一致；重开沿用本局选择，返回战区可以调整难度。
- 现有紫色重甲怪作为 Boss，标准难度约每 4 秒发动一次远程攻击，先有 0.85 秒锁定方向的预警，再发射三枚扇形弹丸。预警期间 Boss 停下，侧移或掩体都可躲避；弹丸先消耗盾牌，不伤其他怪物。
- 波数没有通关上限，每次清关自动推进。小怪与 Boss 数量继续增长，标准难度第11波为38个普通敌人和5个Boss，第30波为95个普通敌人和14个Boss。敌人生命继续增强，速度和出怪间隔有安全界限；同屏最多36个敌人，其余依次入场。出生队列按计数逐个生成，避免后期一次分配巨量怪物数组。
- 六种枪：手枪、冲锋枪、步枪、机枪、狙击枪、霰弹枪；射速、散布、伤害和弹匣各不相同。
- 霰弹枪一次消耗一发弹药，散射七枚弹丸，近距离威力大，远距离伤害衰减，最大射程 300；弹匣六发。
- 地面补给：新武器解锁，重复武器补充相应弹药，以及生命、护盾、手雷补给。
- 护盾是吸收伤害的护甲，上限 100，消耗后通过拾取补充。
- 手雷初始 3 枚；短按沿朝向快投，拖动显示轨迹和实际落点，松手投掷，拖回按钮取消。最远 350，爆炸半径 135、中心伤害 190、边缘最低伤害 76，投出 1.05 秒后爆炸。
- 原换弹按钮改为圆形「爆发」按钮，库存数字与生效进度圈集中显示。开局1个，击杀敌人额外有12%概率掉落金色闪电，拾取后可囤积，最多99个；每次点击消耗1个，当前枪械射速和弹丸速度翻倍8秒。重复使用延长时长，倍率保持两倍；换枪继续享有效果，射程和单发伤害不变，已飞出的弹丸保留发射时的速度。暂停和死亡时计时停止，复活保留剩余时长与库存。
- 单人闯关、失败重开、得分结算和本地最高分记录。每局可免费复活三次，恢复 100 生命、35 护盾，保留当前波次、武器和弹药，头顶显示 3 秒保护倒计时，按钮显示剩余次数。
- 原创合成音效：六种枪声、命中、换弹、拾取、手雷与爆炸、受伤、Boss 预警、复活和关卡提示，共 23 个声音。采用柔和的泡泡和软弹风格。首次操作后启用；菜单或暂停面板可关闭，设置保存在本机。

手枪提供无限备用弹药，并保留弹匣和自动换弹机制，空弹匣继续按住开火即可自动换弹。其他枪械有有限弹药，备用弹药耗尽时可切回手枪；拾取新枪后由玩家自行切换。

每波清关后立即开始下一波，无需等待或确认；补给仍会掉落，靠近即可拾取弹药、盾牌、生命、手雷和爆发道具。第 1、2、3、5、7 波清关分别保底解锁冲锋枪、霰弹枪、步枪、机枪和狙击枪。第10波之后继续闯关，直至角色阵亡。MVP 中手雷投掷会受障碍阻挡，爆炸范围可覆盖障碍另一侧敌人，不伤玩家。

## 操作

| 操作 | 电脑 | 横屏手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆，朝向跟随移动方向 |
| 瞄准、射击 | 鼠标瞄准，按住左键射击 | 按住开火，辅助对准前方可见敌人；拖动开火钮手动瞄准 |
| 换枪 | 1–6 选择 / Q 轮换（6 为霰弹枪） | 开火旁的圆形切枪按钮按顺序轮换已拥有的枪；左上角枪械可展开武器库 |
| 爆发 | R | 原换弹位置的闪电按钮，消耗1个库存，增加8秒效果 |
| 自动换弹 | 弹匣为空后继续开火 | 弹匣为空后继续按住开火，头顶用图形显示换弹进度 |
| 投手雷 | G 快投 / 拖动圆形手雷按钮选择落点 | 短按快投，拖动松手选择落点，拖回按钮取消 |
| 暂停 | Esc / P | 暂停按钮 |

切到后台时暂停战斗，恢复后可继续。手机竖屏时建议旋转到横屏；微信构建固定横屏。

战场铺满横屏，通过跟随角色的视角放大人物、怪物和补给。生命、盾牌、当前武器和弹药集中在左上角；功能文字放大并提高字重与对比度，顶部同时显示本局难度与当前波数。暂停按钮位于左上信息区下方，展开武器库时移到库面板下面，避开微信右上胶囊和操作摇杆。地图选择只用高亮边框和勾标识选中状态；加速带保留箭头动画，清除倍数和装饰标签文字。武器库按需展开，底部不再保留整排装备卡。

手机默认启用“移动转向 + 辅助瞄准”：只辅助前方左右各 36° 内、屏幕可见且没有掩体阻挡的活敌人，最大距离 520，霰弹枪限制为 220（手动射程仍为 300），减少自动射击远处目标时散射浪费。目标显示淡黄色角标，保留同一目标以减少来回跳动。没有合适目标时按原朝向射击；拖动开火按钮优先手动瞄准，可用来打油桶。暂停面板可关闭辅助，电脑鼠标仍由玩家直接瞄准。

## 微信小游戏构建

```sh
npm run build
```

产物位于：

```text
dist/web/       浏览器版：index.html、app.js、source map、assets/audio
dist/wechat/    微信版：game.js、game.json、project.config.json、assets/audio
```

在微信开发者工具中以「小游戏」项目导入 `dist/wechat`。当前源码和已导入工程均使用用户提供的小游戏 AppID `wx1a1efb651d164fae`。用户此前已上传并提交旧版审核，本次本地优化不会自动上传或替换审核中的版本。仅切换账号时，同时修改 `wechat/project.config.json` 和已导入工程 `dist/wechat/project.config.json` 的 AppID，再重新打开工程。开发者工具允许的测试方式和 AppID 权限以实际工具为准。参考 [微信官方小游戏示例配置](https://github.com/wechat-miniprogram/minigame-lockstep-demo/blob/master/project.config.json)。

微信入口使用 `wx.createCanvas`、触摸事件和本地存储；菜单、HUD 与战斗都在 Canvas 内绘制。打包后没有浏览器 DOM 依赖，也没有后端接口。

已验证微信开发者工具的小游戏导入和模拟器运行；浏览器验证覆盖三种横屏尺寸。Android/iOS 真机兼容性、不同机型性能和平台提审仍需验证，当前构建不能等同于已上线微信小游戏。

## 源码结构

```text
src/game.js       战斗、敌人、地图、波次、掉落与装备规则
src/app.js        输入、Canvas 界面与游戏状态切换
src/render.js     原创角色、场景、HUD 与战斗效果绘制
src/aim.js        前方目标筛选、视线检查与辅助瞄准
src/audio.js      浏览器与微信音效播放、静音及生命周期
src/audio-synthesis.js 原创声音生成规则
src/browser.js    浏览器启动及输入、页面生命周期适配
wechat/game.js    微信启动及触摸、后台生命周期适配
scripts/build.mjs  两个平台打包
scripts/serve.mjs  浏览器本地服务
web/index.html    浏览器页面
```

浏览器和微信共用玩法与渲染代码；画布使用逻辑像素输入，由应用处理设备像素比。

## 原创素材与范围

人物、怪物、地图、界面和效果均由本项目 Canvas 代码绘制，音效由本项目声音规则合成，不引用《僵尸危机 3》/Boxhead 或其他游戏的美术、音效、地图或源代码。此版本采用通用的俯视射击、波次闯关与拾取补给机制。新增素材时继续保留作者和授权信息；项目的原创制作说明不构成法律结论。

MVP 暂未包含联网双人、排行榜服务、微信登录、广告、付费、持久账号系统或正式发行配置。
